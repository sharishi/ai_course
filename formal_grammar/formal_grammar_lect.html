01

Введение: язык как множество слов

Русский язык бесконечен: предложений можно составить сколько угодно. Но выучить бесконечный список нельзя. Мы знаем конечный набор правил и по нему строим и понимаем любые новые предложения. Формальная грамматика делает то же самое строго: конечный набор правил описывает бесконечное множество слов.

АлфавитКонечный набор символов. Пример: { a, b, c } или { 0, 1, 2 }.
СловоКонечная последовательность символов алфавита: abbc, 00112. Пустое слово обозначают ε.
ЯзыкМножество слов, обычно бесконечное: { b, bb, abc, aabcc, … }.

С грамматикой связаны две задачи:

ПорождениеПо правилам получить слова языка. Этим мы занимаемся, когда строим вывод.
РаспознаваниеДано слово: принадлежит ли оно языку? Это мы делаем в задании 3.

  3. сейчасГрамматики ограничивают ответы языковых моделей, чтобы они выдавали корректный JSON, SQL или код.
02

Зачем грамматики в искусственном интеллекте

Грамматики — один из самых старых инструментов ИИ, и сегодня они снова в работе. Везде, где машина должна понять или выдать текст строгой структуры, за этим стоит грамматика.

Языковые модели и структурированный ответМодель выбирает следующий токен. Грамматика заранее запрещает токены, после которых слово уже не может попасть в язык. Так модель гарантированно выдаёт правильный JSON, SQL или вызов функции. Такие ограничения поддерживают, например, llama.cpp (формат GBNF) и режимы structured output у API моделей.
Разбор естественного языкаПредложение раскладывается в дерево по грамматике: подлежащее, сказуемое, дополнение. Дерево помогает понять, кто что делает. Пример — ниже.
Поиск в тексте и токенизацияРегулярные грамматики (тип 3, о них ниже) лежат в основе регулярных выражений. Ими находят в тексте даты, суммы, e-mail и делят текст на токены перед подачей в модель.
Код и компиляторыЛюбая программа на Python перед запуском разбирается по грамматике языка. SyntaxError означает ровно одно: ваш текст не принадлежит языку Python.

Пример 1. Грамматика как фильтр для языковой модели

Языковая модель пишет ответ по кусочку: на каждом шаге выбирает, что дописать дальше. Если ответ должен иметь строгий вид (например, JSON), к модели подключают грамматику. Перед каждым шагом грамматика проверяет все варианты и оставляет только те, после которых ответ ещё можно закончить правильно.

03

Что такое грамматика

все задания

Грамматика записывается четвёркой G = (VN, VT, P, S). Каждая буква четвёрки — отдельная часть.

VNНетерминалы — «заготовки», которые ещё будут заменены. Пишем большими буквами: SA
VTТерминалы — буквы готового слова. Их уже не заменяют: abc
PПравила вида X → …: «нетерминал X можно заменить на то, что справа».
SНачальный символ. С него начинается любой вывод.

Всю лекцию мы работаем с одной грамматикой из примера решения:

G = (VN, VT, P, S); VN = { S, A }, VT = { a, b, c }
P = { 1. S → aSc   2. S → A   3. A → bA   4. A → b }

Типы грамматик: иерархия Хомского

Грамматики делят на четыре типа по виду правил. Чем строже правила, тем меньше языков можно описать. Нажмите на язык и посмотрите, какой самый простой тип для него нужен.

ТипВид правилПример
3, регулярныеA → aB, A → aa*b*, идентификаторы, числа
2, контекстно-свободныеслева ровно один нетерминал: A → γнаша G, скобки, языки программирования
1, контекстно-зависимыезамена с учётом соседей: αAβ → αγβaⁿbⁿcⁿ
0, неограниченныелюбые правилавсё, что может посчитать машина Тьюринга

Все грамматики лабораторной контекстно-свободные: слева в каждом правиле один нетерминал. Язык грамматики 2 (a²ⁿbc) даже регулярный: считать пары не нужно, достаточно проверять чётность.

Вывод — это цепочка замен от S до слова, где не осталось ни одного нетерминала. Запись aSc ⇒ aaScc читается так: «в цепочке aSc заменили S по правилу 1».

    Памятка: как решать такие задачи

    1. Разметить правила. У каждого нетерминала найти правила «повторяется» (нетерминал остаётся справа) и «выход» (не остаётся).
    2. Понять, что добавляет каждое правило. Повторяющиеся правила дают степени n, k, m; выходные применяются один раз.
    3. Записать язык и проверить на 2–3 самых коротких словах. Отдельно проверить границы: может ли показатель быть 0.
    4. Чтобы доказать «не принадлежит», строить вывод по первой букве и показать шаг, где не подходит ни одно правило.
    5. Чтобы построить грамматику, найти пары равных букв, вложить их матрёшкой и на каждый уровень завести нетерминал. Выход: bc, если пар минимум одна, и ε, если пар может не быть.
