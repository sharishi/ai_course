01

Introducere: limbajul ca mulțime de cuvinte

Limba română este infinită: putem alcătui oricâte propoziții. Dar o listă infinită nu poate fi învățată. Cunoaștem un set finit de reguli și, după el, construim și înțelegem orice propoziție nouă. O gramatică formală face același lucru, riguros: un set finit de reguli descrie o mulțime infinită de cuvinte.

AlfabetUn set finit de simboluri. Exemplu: { a, b, c } sau { 0, 1, 2 }.
CuvântO secvență finită de simboluri din alfabet: abbc, 00112. Cuvântul vid se notează ε.
LimbajO mulțime de cuvinte, de obicei infinită: { b, bb, abc, aabcc, … }.

Cu o gramatică sunt legate două probleme:

GenerareaObținerea cuvintelor limbajului după reguli. Asta facem când construim o derivare.
RecunoaștereaSe dă un cuvânt: aparține el limbajului? Asta facem în sarcina 3.

De unde provine

  1. 1956Noam Chomsky propune clasificarea gramaticilor după forma regulilor. Așa apare ierarhia despre care vorbim mai jos.
  2. 1960Sintaxa limbajului ALGOL 60 este scrisă în forma Backus–Naur (BNF). De atunci, limbajele de programare se descriu prin gramatici.
  3. aziGramaticile restricționează răspunsurile modelelor de limbaj, ca acestea să producă JSON, SQL sau cod corect.
02

De ce sunt necesare gramaticile în inteligența artificială

Gramaticile sunt unul dintre cele mai vechi instrumente ale IA, iar astăzi sunt din nou folosite. Oriunde o mașină trebuie să înțeleagă sau să producă un text cu structură strictă, în spate stă o gramatică.

Modele de limbaj și răspuns structuratModelul alege următorul token. Gramatica interzice dinainte tokenii după care cuvântul nu mai poate ajunge în limbaj. Astfel modelul produce garantat JSON, SQL sau un apel de funcție corect. Astfel de restricții sunt suportate, de exemplu, de llama.cpp (formatul GBNF) și de modurile structured output ale API-urilor de modele.
Analiza limbajului naturalPropoziția se descompune într-un arbore după gramatică: subiect, predicat, complement. Arborele ajută să înțelegem cine ce face. Exemplu — mai jos.
Căutare în text și tokenizareGramaticile regulate (tipul 3, despre ele mai jos) stau la baza expresiilor regulate. Cu ele se găsesc în text date, sume, adrese de e-mail și se împarte textul în tokeni înainte de a-l da modelului.
Cod și compilatoareOrice program în Python este analizat după gramatica limbajului înainte de rulare. SyntaxError înseamnă un singur lucru: textul vostru nu aparține limbajului Python.

Exemplul 1. Gramatica drept filtru pentru un model de limbaj

Un model de limbaj scrie răspunsul bucată cu bucată: la fiecare pas alege ce să adauge. Dacă răspunsul trebuie să aibă o formă strictă (de exemplu, JSON), modelului i se atașează o gramatică. Înainte de fiecare pas, gramatica verifică toate variantele și le păstrează doar pe cele după care răspunsul mai poate fi terminat corect.

Să arătăm asta pe limbajul nostru aⁿbᵏcⁿ. Mai jos sunt începutul deja scris al cuvântului și patru variante de continuare. Pentru fiecare se vede dacă gramatica o permite și de ce.

La fel funcționează JSON: după {"age": gramatica va permite un număr sau un șir, dar va interzice }, pentru că valoarea încă nu a fost scrisă.

Exemplul 2. Analiza unei propoziții

O gramatică poate descrie și limba obișnuită. Neterminalele aici sunt părțile propoziției, terminalele sunt cuvintele. Derivați propoziția la fel cum ați derivat aabbbcc în secțiunea 4: apăsați pe reguli.

P = { 1. Propoziție → Subiect Predicat   2. Subiect → pisica   3. Subiect → câinele   4. Predicat → vede Complement   5. Complement → șoarecele   6. Complement → mingea }

Din arbore se vede ce rol are fiecare cuvânt: „pisica” este subiectul, „șoarecele” este complementul. Programele care analizează textul construiesc exact astfel de arbori.

03

Ce este o gramatică

toate sarcinile

O gramatică se scrie ca un cvadruplu G = (VN, VT, P, S). Fiecare literă a cvadruplului este o parte distinctă.

VNNeterminalele sunt „semifabricate” care vor fi înlocuite. Le scriem cu majuscule: SA
VTTerminalele sunt literele cuvântului final. Ele nu se mai înlocuiesc: abc
PReguli de forma X → …: „neterminalul X poate fi înlocuit cu ce este în dreapta”.
SSimbolul de start. Orice derivare începe cu el.

Pe tot parcursul cursului lucrăm cu o singură gramatică din exemplul de rezolvare:

G = (VN, VT, P, S); VN = { S, A }, VT = { a, b, c }
P = { 1. S → aSc   2. S → A   3. A → bA   4. A → b }

Tipuri de gramatici: ierarhia Chomsky

Gramaticile se împart în patru tipuri după forma regulilor. Cu cât regulile sunt mai stricte, cu atât mai puține limbaje pot fi descrise. Apăsați pe un limbaj și vedeți de ce tip minim are nevoie.

TipForma regulilorExemplu
3, regulateA → aB, A → aa*b*, identificatori, numere
2, independente de contextîn stânga exact un neterminal: A → γG-ul nostru, paranteze, limbaje de programare
1, dependente de contextînlocuire ținând cont de vecini: αAβ → αγβaⁿbⁿcⁿ
0, fără restricțiiorice regulitot ce poate calcula o mașină Turing

Toate gramaticile din laborator sunt independente de context: în stânga fiecărei reguli este un singur neterminal. Limbajul gramaticii 2 (a²ⁿbc) este chiar regulat: nu trebuie numărate perechi, ajunge verificarea parității.

Derivarea este un șir de înlocuiri de la S până la un cuvânt în care nu a rămas niciun neterminal. Notația aSc ⇒ aaScc se citește așa: „în șirul aSc l-am înlocuit pe S după regula 1”.

04

Derivarea pas cu pas și arborele de derivare

sarcina 2

Derivați cuvântul singuri: apăsați pe o regulă și ea va înlocui neterminalul încadrat. În derivarea la stânga se înlocuiește mereu neterminalul cel mai din stânga. Mai jos crește simultan arborele: fiecare regulă îi dă nodului descendenți — simbolurile părții drepte, de la stânga la dreapta.

Cum citim arborele: frunzele (nodurile fără descendenți), de la stânga la dreapta, dau cuvântul final. Pentru aabbbcc acestea sunt a, a, b, b, b, c, c.

    Rezumat: cum rezolvăm astfel de probleme

    1. Marcați regulile. Pentru fiecare neterminal găsiți regulile „se repetă” (neterminalul rămâne în dreapta) și „ieșire” (nu rămâne).
    2. Înțelegeți ce adaugă fiecare regulă. Regulile care se repetă dau exponenții n, k, m; cele de ieșire se aplică o singură dată.
    3. Scrieți limbajul și verificați-l pe 2–3 cele mai scurte cuvinte. Verificați separat limitele: poate exponentul să fie 0?
    4. Pentru a demonstra „nu aparține”, construiți derivarea după prima literă și arătați pasul la care nu se potrivește nicio regulă.
    5. Pentru a construi o gramatică, găsiți perechile de litere egale, încadrați-le ca o matrioșkă și introduceți un neterminal pentru fiecare nivel. Ieșirea: bc, dacă există cel puțin o pereche, și ε, dacă perechile pot lipsi.
