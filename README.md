# AI Course – Moldova State University (USM)

This repository contains materials for the **Artificial Intelligence** course taught at Moldova State University (USM).

## Contents
- **Lectures** – course lecture materials
- **Examples** – example solutions to course tasks

## Languages
The materials are available in two languages, each in its own branch:

| Branch | Language |
|--------|----------|
| `ru`   | Russian  |
| `ro`   | Romanian |

Switch to the branch in your preferred language:

- git checkout ru   # Russian
- git checkout ro   # Romanian

## Getting Started
Clone a specific branch directly:

- `git clone -b ru https://github.com/<your-username>/ai_course.git`
- `git clone -b ro https://github.com/<your-username>/ai_course.git`

## Purpose
These materials are intended for educational use by USM students.
